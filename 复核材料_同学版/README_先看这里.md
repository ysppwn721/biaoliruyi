# 知链人工复核材料

本包用于复核 Word 论断与 Excel 事实的来源关系，共 280 条。请独立判断，不参考其他人的标注结果。

## 文件

- `长文测试_原始报告.docx`：原始报告。
- `配套数据_初始.xlsx`：原始事实表。
- `人工复核清单_盲评版.csv`：需要填写的唯一工作表。
- `复核操作指南_同学版.md`：字段和判断规则。
- `复核完成回传说明.md`：填写完成后的回传要求。

## 提交结果

只需要回传填写后的 `人工复核清单_盲评版.csv`。不要修改 claim_id、claim_text、facts_json 和 source_location，以便程序自动合并。

复核的是来源是否唯一，不是先判断数字是否正确。数字和文本不一致时，只要来源唯一，仍填写 `link`，并在备注说明数值冲突。
