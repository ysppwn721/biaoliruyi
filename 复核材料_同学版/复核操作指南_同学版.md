# 复核操作指南

## 每条记录怎么复核

1. 用 `claim_text` 在 Word 中找到原文；需要时参考 `source_location`。
2. 在 Excel 中核对事实 ID、主体、指标、期间、单位和统计口径。
3. 判断来源是否唯一。
4. 填写最后四列：
   - `reviewer_decision`：`link` 或 `abstain`。
   - `reviewer_refs`：事实 ID；多个 ID 用英文逗号分隔。
   - `reviewer_category`：`ordinary`、`ambiguous` 或 `adversarial`。
   - `reviewer_note`：判断依据、冲突或不确定原因。

## 判断规则

- 普通数值引用通常关联一个事实。
- 增长率需要上期和本期两个事实，顺序按“上期,本期”。
- 排名需要完整比较集合，不能只填第一名。
- “支出未超过预算”需要支出和预算两个事实。
- 同指标同期间存在多个统计口径时填 `abstain` 和 `ambiguous`。
- Word 数字与 Excel 数值不一致时，来源仍可能唯一。此时填 `link`，在备注中写“来源唯一，但数值不一致”。
- 找不到事实或无法判断时填 `abstain`。

## 注意

清单是盲评版，没有提供候选答案。请不要自行补充事实 ID，也不要参考项目中其他评测结果。
