# 知链 · Windows 安装包 · 安装与使用说明

知链是可本地运行的 Web 应用。本目录同时提供标准安装版和免安装绿色版，均无需安装 Python、无需安装 Office 服务。

标准安装版支持选择安装位置、开始菜单、可选桌面快捷方式和卸载；免安装版解压后双击 `启动知链.bat`，浏览器自动打开工作台。

## 一、环境要求

- Windows 10/11（64 位）
- 标准安装版和免安装版均自带运行环境，不需要单独安装 Python
- 本地模型和 DeepSeek API 为可选功能；未配置时仍可使用规则和智能体流程
- 浏览器：Chrome / Edge / Firefox

## 二、标准安装版（推荐）

双击 `知链_v0.2.1_Windows安装版.exe`，按向导选择安装目录。默认目录为：

`%LOCALAPPDATA%\Programs\Zhilian`

安装完成后，可从开始菜单或桌面快捷方式启动。卸载不会删除用户项目数据，项目数据默认位于：

`%LOCALAPPDATA%\Zhilian`

## 三、免安装版

1. 解压本包到任意目录（路径不要含中文或空格，例如 `D:\zhilian`）。
2. 双击 `启动知链.bat`。
3. 浏览器访问 http://127.0.0.1:8765 。

## 四、快速体验

1. 登录后点击“体验演示项目”。
2. “批量确认候选关联”确认来源。
3. “载入演示变更” → “更新数据并验证”。
4. “预览修复” → “确认修复并复核”。
5. “导出成果”下载 Word/PPT 与核验记录。

## 五、导入自己的文件

事实表需包含 7 列：`事实ID / 主体 / 指标 / 期间 / 数值 / 单位 / 统计口径`（列顺序可变，事实 ID 唯一）。
点击“导入我的文件”，选择一份 `.xlsx` 和至少一份 `.docx`/`.pptx`（最多 10 份、合计 30MB）。

## 六、常用配置（`.env`）

| 变量 | 说明 |
| --- | --- |
| `ZHILIAN_HOST` | 监听地址，默认 `127.0.0.1`；局域网/公网设为 `0.0.0.0` |
| `ZHILIAN_PORT` | 端口，默认 `8765` |
| `ZHILIAN_ACCESS_PASSWORD` | 登录密码（用户名固定 `zhilian`） |
| `DEEPSEEK_API_KEY` | 可选，DeepSeek 密钥；留空则纯规则模式运行 |
| `DEEPSEEK_MODEL` | 模型 ID，默认 `deepseek-flash` |

公网部署请使用 HTTPS 反向代理，不要直接暴露明文 Basic Auth 端口。

## 七、其他启动方式

```powershell
.\start.ps1          # PowerShell 启动（效果等同 启动知链.bat）
.\.venv\Scripts\python.exe run.py
```

## 八、停止

在启动窗口按 `Ctrl+C`，或直接关闭该命令行窗口。
