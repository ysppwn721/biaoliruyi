# 知链 · Windows 免安装包 · 安装与使用说明

知链是可本地运行的 Web 应用，本包为“解压即用”的 Windows 免安装绿色包：无需编译、无需安装服务，
解压后双击 `启动知链.bat`，浏览器自动打开工作台。

## 一、环境要求

- Windows 10/11
- Python 3.11 及以上（若未安装，请到 https://www.python.org/downloads/ 下载，安装时勾选 **Add Python to PATH**）
- 首次启动需联网安装依赖（约 1–2 分钟）；之后可离线使用
- 浏览器：Chrome / Edge / Firefox

## 二、安装（三步）

1. 解压本包到任意目录（路径不要含中文或空格，例如 `D:\zhilian`）。
2. 双击 `启动知链.bat`。
3. 首次运行会自动创建虚拟环境并安装依赖，然后自动打开 http://127.0.0.1:8765 。

## 三、登录（测试账号）

> **密码：`zhilian2026`**

本包自带 `.env` 已启用该测试账号。所有页面与接口均受 Basic 认证保护。

## 四、快速体验

1. 登录后点击“体验演示项目”。
2. “批量确认候选关联”确认来源。
3. “载入演示变更” → “更新数据并验证”。
4. “预览修复” → “确认修复并复核”。
5. “导出成果”下载 Word/PPT 与核验记录。

## 五、导入自己的文件

事实表需包含 7 列：`事实ID / 主体 / 指标 / 期间 / 数值 / 单位 / 统计口径`（列顺序可变，事实 ID 唯一）。
点击“导入我的文件”，选择一份 `.xlsx` 和至少一份 `.docx`/`.pptx`（最多 10 份、合计 30MB）。

## 六、常用配置（`.env`）

| 变量 | 说明 |
| --- | --- |
| `ZHILIAN_HOST` | 监听地址，默认 `127.0.0.1`；局域网/公网设为 `0.0.0.0` |
| `ZHILIAN_PORT` | 端口，默认 `8765` |
| `ZHILIAN_ACCESS_PASSWORD` | 登录密码（用户名固定 `zhilian`） |
| `DEEPSEEK_API_KEY` | 可选，DeepSeek 密钥；留空则纯规则模式运行 |
| `DEEPSEEK_MODEL` | 模型 ID，默认 `deepseek-flash` |

公网部署请使用 HTTPS 反向代理，不要直接暴露明文 Basic Auth 端口。

## 七、其他启动方式

```powershell
.\start.ps1          # PowerShell 启动（效果等同 启动知链.bat）
.\.venv\Scripts\python.exe run.py
```

## 八、停止

在启动窗口按 `Ctrl+C`，或直接关闭该命令行窗口。
