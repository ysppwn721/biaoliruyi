# 知链双智能体标注复核操作指南

## 你需要准备

1. 原始 Word：`长文Word测试/长文测试_原始报告.docx`。
2. 原始 Excel：`长文Word测试/配套数据_初始.xlsx`。
3. 复核表：`双智能体标注复核清单.csv`。
4. Excel/WPS 或文本编辑器。

## 复核目标

你复核的是“这条 Word 论断应该关联哪些事实 ID”，不是先判断当前数字是否正确。

- 来源唯一：`reviewer_decision=link`，填写事实 ID。
- 来源不唯一、统计口径冲突或缺少必要事实：`reviewer_decision=abstain`，`reviewer_refs` 留空。
- 文本中的数值与 Excel 数值不一致：仍然可以填写 `link`，并在 `reviewer_note` 写“来源唯一，但当前值不一致，交给引擎诊断”。

## 每行的操作

1. 按 `source_location` 在 Word 中定位原文。`p` 表示正文段落，`t` 表示表格；定位困难时搜索 `claim_text`。
2. 在 Excel 中找到对应事实 ID，核对主体、指标、期间、单位、统计口径。
3. 查看 `candidate_refs` 和 `consensus_refs`，它们只是两个子智能体的参考结果，不是必须接受的答案。
4. 判断来源是否唯一，并填写最后四列：

   - `reviewer_decision`：`link` 或 `abstain`。
   - `reviewer_refs`：一个或多个事实 ID，多个 ID 用英文逗号分隔。
   - `reviewer_category`：`ordinary`、`ambiguous` 或 `adversarial`。
   - `reviewer_note`：简要写依据或分歧。

## 四类论断怎么判断

### 数值引用

“本期销售额为125万元”通常只关联 `sales_current`。要同时核对主体、期间、单位和口径。

### 增长率

“较上期增长25%”需要两个事实：上期和本期。通常填写 `sales_prev,sales_current`，顺序按上期到本期。

### 排名

“A产品销量最高”需要完整比较集合，例如 `product_a,product_b`。不能只填第一名，因为引擎需要比较其他对象。

### 阈值和预算

“本期支出低于100万元”只关联 `spending`；“支出未超过预算”需要 `spending,budget`。

如果 Excel 中支出为80万元而 Word 写“超过100万元”，来源仍是 `spending`，但在备注中写明“来源唯一、数值不一致”。这是后续确定性诊断和修复的数据，不属于来源歧义。

## 复核优先顺序

先复核 `numeric_conflict_note=是` 的行，再复核增长率、排名和预算比较，最后抽查普通数值引用。每个文档组至少抽查 2 条，建议完整复核全部 280 条。

## 复核完成后的检查

- `reviewer_decision` 不得为空。
- `link` 行的 `reviewer_refs` 不得为空，且每个 ID 必须存在于该行的 facts。
- `abstain` 行的 `reviewer_refs` 应为空。
- `reviewer_note` 应说明歧义来源或数值冲突。
- 复核结果与两个子智能体不同的行单独列出，作为最终人工仲裁项。

复核表只是给队员使用的工作副本，不要覆盖 `real_human_eval_dataset.jsonl`。复核完成后把 CSV 交回，再由程序转换并重新运行评测。
