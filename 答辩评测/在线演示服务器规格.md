# 在线演示服务器规格（实测）

更新时间：2026-09-26
实测脚本：`答辩评测/measure_runtime_footprint.py`（可复现）

## 一、实测占用

| 阶段 | RSS |
| --- | ---: |
| 起始 | 18.6 MB |
| 导入 FastAPI 应用 | 79.6 MB |
| 读取事实表 | 80.2 MB |
| **载入本地 ONNX 重排模型** | **1,176.7 MB** |
| 连续 432 对推理后 | 1,192.9 MB |
| 完整导入闭环后 | **1,205.7 MB（峰值）** |

结论：**空载只要约 80 MB，本地模型一载入就是 1.2 GB。** 差 15 倍，规格就看这一项。

CPU 占用（本机 24 线程，ONNX 默认吃满）：

- 432 对推理：墙钟 8.3 s，而进程累计 CPU 196.7 s → 折算 **0.455 s CPU / 对**
- 模型加载本身约 17.5 s CPU（冷启动一次性）
- 演示项目只有个位数到几十对需要重排 → **2 核机器上约 5–20 s**，可接受

其他事实：

- **没有本地 OCR 引擎**：`zhilian/ocr.py` 只调 API 与人工确认，不占内存
- 线上只需要 `bge-reranker-v2-m3-onnx-int8`（**560 MB**）。
  `bert-base-chinese`（1.63 GB）与 `zh_reranker_bert_ft_v2_onnx`（391 MB）都是训练用，线上不需要
- Python 依赖体积：onnxruntime 221 MB、pandas 61 MB、numpy 32 MB、tokenizers 7.8 MB
  → Docker 镜像估 **0.9–1.2 GB**，加模型约 **1.5–1.8 GB**
- 下载包（Windows 25 MB 等）由 Cloudflare Worker 提供，**不走服务器带宽**

## 二、推荐规格

| 方案 | 规格 | 判断 |
| --- | --- | --- |
| **推荐 · 开启本地重排** | **2 核 4 GB / 40 GB SSD** | 模型常驻 1.2 GB，余量给系统与并发；**uvicorn 只开 1 个 worker** |
| 稳妥 · 多人同时操作 | **4 核 8 GB** | 同时 5 人以上跑大文件时更从容；CPU 是瓶颈而非内存 |
| 最低可用 · 开本地重排 | 2 核 2 GB | 能跑但很紧（1.2 GB 模型 + 系统 + Docker 易触发 swap），**不建议** |
| **最省 · 仅规则或在线 API 兜底** | **1 核 1 GB** | 空载仅 80–200 MB，完全够用 |

⚠️ **不要买突发性能实例（阿里云 t5/t6、腾讯云标准型 S5 的轻量变体等）**：
ONNX 推理会把 CPU 打满，突发积分耗尽后会被限频，演示时表现为"越点越慢"。
选通用型 / 计算型 / 轻量应用服务器即可。

## 三、为什么服务器其实可以很小（建议的架构）

`zhilian.space` 现在绑定的是 Cloudflare Worker `biaoliruyi`（只提供静态站点）。
最省的做法是**让 Worker 继续管静态页，只把 `/demo/*` 与 `/api/*` 转发到服务器**：

```text
zhilian.space
├── / 与下载页         → Cloudflare Worker 静态资源（不占服务器）
├── /demo/*            → Worker fetch → 云服务器 :8765
└── /api/*             → Worker fetch → 云服务器 :8765
```

这样服务器**不需要 80/443、不需要证书、不需要公网域名绑定**，只需一个端口可达，
带宽需求也极低（只有演示流量）。Caddy 那套可以不用——`deploy/` 里的 compose
仍可用于"服务器直出整站"的方案，二选一即可。

如果连公网端口都不想开：那台 CTF 机器上已经在跑 `cloudflared`，
说明你熟悉 Cloudflare Tunnel；用 Tunnel 从新服务器出站即可，无需安全组放行。

## 四、下单时要一并确认的三件事

1. **模型怎么上服务器**：`models/` 被 `.gitignore` 排除，GitHub 也放不下
   （单文件限 100 MB）。需要 `scp -r models/bge-reranker-v2-m3-onnx-int8` 上传，
   或在服务器上从 HuggingFace 拉取。**没有模型不会崩**，会自动降级为规则模式。
2. **镜像里要带模型**：现有 `Dockerfile` 只 COPY 了 `zhilian/ web/ run.py`，
   要跑本地重排需额外挂载模型目录（`-v` 或补一条 COPY）。
3. **常驻与续期**：容器设 `restart: unless-stopped`；演示有效期要覆盖到 11/14 决赛之后。
