# 域名接入 Cloudflare Pages（zhilian.space）

> 当前进度：域名已在**阿里云**注册成功，但处于 **`client hold`** 状态，需先在阿里云解除。
> 本文说明解除后如何把站点与演示环境接到该域名上。

## 一、先解除 `client hold`（当前唯一阻塞）

注册局 RDAP 查询结果：

```
注册商 : Alibaba Cloud Computing Ltd. (HiChina)
状态   : client transfer prohibited, client hold, client renew prohibited, add period
NS     : dns29.hichina.com, dns30.hichina.com
```

`client hold` 表示**注册商暂停了解析**，因此在 DNS 上表现为"域名不存在"：

```
nslookup zhilian.space 8.8.8.8    → Non-existent domain
nslookup zhilian.space 223.5.5.5  → Non-existent domain
```

**最可能原因：实名认证未完成。** 阿里云注册的域名要求实名；未通过时会挂 `client hold`。

### 处理步骤

1. 登录阿里云 → 控制台 → **域名**
2. 找到 `zhilian.space`，查看状态提示
3. 若显示**待实名认证**或**实名认证审核中**：
   - 进入「域名持有者信息」/「信息模板」
   - 用**个人身份证**或**企业营业执照**提交实名材料
   - 通常 **1 个工作日内**通过
4. 若提示订单未完成 → 完成支付
5. 解除后验证：

```powershell
nslookup -type=SOA zhilian.space 223.5.5.5
```

能返回 SOA 即表示解析已恢复。

## 二、备案说明（重要）

| 情形 | 是否需要 ICP 备案 |
| --- | --- |
| 解析到**大陆境内主机** | **需要**，约 1–3 周，需主体资质 |
| 解析到 **Cloudflare / 境外主机** | **不需要** |

**本方案属于后者，因此不需要备案。** 域名在阿里云注册并不触发备案义务，
备案义务来自"使用大陆境内服务器提供互联网信息服务"。

> `zhilian.space` 属于普通国际顶级域；若日后改用 `.cn` 域名，
> 阿里云会强制要求实名，规则更严。

## 三、把站点接到域名（Cloudflare Pages）

### 步骤 1：把 DNS 托管迁到 Cloudflare

Cloudflare Pages 的自定义域名要求 DNS 由 Cloudflare 托管。

1. Cloudflare 控制台 → **Add a site** → 输入 `zhilian.space` → 选 **Free** 计划
2. Cloudflare 会分配两个名称服务器，形如：

   ```
   xxxx.ns.cloudflare.com
   yyyy.ns.cloudflare.com
   ```

3. 回到**阿里云** → 域名 → `zhilian.space` → **DNS 修改 / 修改 DNS 服务器**
4. 把原来的 `dns29.hichina.com`、`dns30.hichina.com` 换成上一步 Cloudflare 给的两个地址
5. 等待生效（通常几十分钟，最长 24 小时），Cloudflare 会发邮件通知

> ⚠️ 阿里云侧若仍处于 `client hold`，改 NS 也不会生效——**必须先完成第一节的实名认证**。

### 步骤 2：部署站点

Cloudflare 控制台 → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**

| 设置项 | 填什么 |
| --- | --- |
| 仓库 | `ysppwn721/biaoliruyi` |
| Project name | `biaoliruyi` |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | **留空** |
| **Build output directory** | **`site`** |

部署完成后得到 `biaoliruyi.pages.dev` 地址。

### 步骤 3：绑定自定义域名

Pages 项目 → **Custom domains** → **Set up a custom domain**

- 添加 `zhilian.space`（根域）
- 再添加 `www.zhilian.space`（会自动配置跳转）

Cloudflare 会自动写入所需的 DNS 记录，证书由 Cloudflare 自动签发（免费）。

**注意**：`site/` 里的下载链接为相对路径（`downloads/xxx.zip`），
因此绑定域名后下载链接自动生效，无需改动代码。

最后把 `site/index.html` 里的演示地址改为自有域名：

```javascript
window.DEMO_URL = 'https://demo.zhilian.space';
```

## 四、把演示环境接到子域名

演示环境是常驻 Python 服务，需要隧道或云主机。

### 方式 A：命名隧道（指向本机，零成本）

```powershell
# 1. 登录（浏览器授权，写入 ~/.cloudflared/cert.pem）
cloudflared tunnel login

# 2. 创建命名隧道
cloudflared tunnel create biaoliruyi

# 3. 绑定子域名（自动写入 CNAME）
cloudflared tunnel route dns biaoliruyi demo.zhilian.space

# 4. 写 ~/.cloudflared/config.yml
#    tunnel: <上一步返回的隧道ID>
#    credentials-file: C:\Users\<你>\.cloudflared\<隧道ID>.json
#    ingress:
#      - hostname: demo.zhilian.space
#        service: http://127.0.0.1:8765
#      - service: http_status:404

# 5. 运行
cloudflared tunnel run biaoliruyi
```

### 方式 B：境外云主机（推荐，稳定）

```bash
docker build -t biaoliruyi .
docker run -d --name biaoliruyi -p 8765:8765 \
  -e ZHILIAN_ACCESS_PASSWORD=zhilian2026 \
  -e ZHILIAN_HOST=0.0.0.0 \
  -v biaoliruyi-data:/data \
  --restart unless-stopped biaoliruyi
```

再把 `demo.zhilian.space` 以 A 记录指向该主机 IP（Cloudflare 代理开关可开启）。
