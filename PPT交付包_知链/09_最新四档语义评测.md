# 最新四档语义评测素材（必须替换旧版同名结论）

## 数据口径

- 数据集：72 条中文自然语言语义改写论断。
- 事实表：固定的 6 条业务事实。
- 规则唯一候选：15 条；规则零候选：57 条。
- API：DeepSeek 实际调用 2 批，72 条论断，成功率 100%。
- gold：由固定事实表程序化生成，只用于评测，不能称为真实行业人工真值。

## 最终表格

| 配置 | Top-1 | 错误关联率 | 覆盖率 | 拒答率 |
|---|---:|---:|---:|---:|
| 纯规则 | 19.44% | 1.39% | 20.83% | 79.17% |
| 单独本地 BGE | 87.50% | 12.50% | 100.00% | 0.00% |
| 规则 + 本地 BGE | 87.50% | 12.50% | 100.00% | 0.00% |
| 规则 + 本地 BGE + API | **93.06%** | **4.17%** | **97.22%** | 2.78% |

## 答辩解释

单独本地模型和规则+本地模型相同，是因为规则唯一确定时直接采用规则，规则零候选时交给 BGE；两者覆盖了相同的语义排序场景。API 不负责全量重做，而是复核 BGE 的低置信结果：它把 Top-1 从 87.50% 提升到 93.06%，把错误关联率从 12.50% 降到 4.17%，并对 2 条不确定样本安全拒答。

三个指标的含义：

- **Top-1**：首选事实与 gold 一致的比例。
- **错误关联率**：已经给出来源但来源错误的比例。
- **拒答率**：没有给出来源、转人工确认的比例。

## 推荐口播

> 纯规则只能命中 20.83% 的语义改写。单独 BGE 和规则加 BGE 都达到 87.50%，说明本地模型解决了同义改写和隐含期间问题，但直接全量采用会产生 12.50% 的错误关联。我们让 API 只复核低置信结果，Top-1 提升到 93.06%，错误关联率降到 4.17%，同时保留少量安全拒答。系统的分工是规则保证确定性，本地模型做语义召回，API 处理难例，最终来源仍由用户确认。
