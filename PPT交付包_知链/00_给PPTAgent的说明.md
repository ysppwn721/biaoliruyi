# 知链答辩 PPT 内容包

本目录交给负责生成 PPT 的 Agent 使用。目标是制作一套 10–12 页、中文、技术答辩风格的演示文稿，主题为“知链：基于证据链智能体的跨文档结论验证与增量修复”。

## 使用规则

1. 以 `README_最终使用说明.md`、`01_PPT页级文案.md` 作为逐页内容来源，以 `02_PPT生成提示词.txt` 作为生成指令；`09_最新四档语义评测.md` 覆盖旧版模型对比数字。
2. 直接使用 `images/` 中的 SVG；SVG 可在 PowerPoint 中作为矢量图使用，也可转为 PNG。
3. 文案中的“已验证”与“规划”必须分开。不要把本地测试夹具称为行业泛化数据。
4. API 指标、长文夹具指标、规则回放指标必须分别标注数据集来源。
5. 不要在 PPT、图片、备注或提示词中出现真实 API Key。

## 推荐视觉风格

白色或浅灰背景，深蓝作为主色，青绿色表示通过，橙色表示待确认，紫色表示模型工具。每页只保留一个结论，图表下方添加小字数据口径。避免堆砌代码截图。
