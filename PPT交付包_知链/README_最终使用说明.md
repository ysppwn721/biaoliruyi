# 知链 PPT 素材包最终使用说明

这份目录交给负责制作 PowerPoint 的队友。优先使用本说明、`01_PPT页级文案.md`、`09_最新四档语义评测.md` 和 `10_技术说明文档_知链_v0.2.1.md`。

## 文件使用顺序

1. `01_PPT页级文案.md`：13 页主体结构和逐页内容。
2. `09_最新四档语义评测.md`：替换旧版四档对比数字和讲稿。
3. `02_PPT生成提示词.txt`：视觉和生成约束。
4. `04_演示讲稿.md`：演示过程口播。
5. `10_技术说明文档_知链_v0.2.1.md`：技术架构、智能体、模型路由和限制的完整依据。
6. `images/`：所有可直接放进 PPT 的 SVG 图表和架构图。

`system_comparison.csv` 是封闭夹具/历史回放补充数据；模型四档主图必须使用 `semantic_four_way_latest.csv`，不要用旧 CSV 覆盖第 9 页。

## 必须使用的最新素材

- `images/语义四档配置对比.svg`：规则、本地模型、融合和 API 兜底对比。
- `images/知链智能体架构图.svg`：智能体状态机和确定性引擎。
- `images/长文Word修复结果对比.svg`：长文局部修复。
- `images/事实表读取性能曲线.svg`：事实表解析性能。
- `images/真实年报外部验证对比_36份.svg`：公开年报外部压力验证。
- `03_答辩数据.csv` 和 `semantic_four_way_latest.csv`：图表数值来源。

## 不能写进 PPT 的内容

- 不能把程序化 gold 写成“人工行业真值”。
- 不能把规则回放 100% 写成行业准确率。
- 不能把 BERT 内部测试集 100% 写成泛化能力；必须说明存在过拟合。
- 不能声称模型直接改文件，实际改文件前有来源确认和修复批准两道人工闸门。
- 不能出现 API Key、服务器密码或个人隐私。
- 规划中的 OCR、多模态、百文档并行和客户端适配必须标记为“下一阶段”。

## 推荐最终结构

13 页即可：问题 → 目标与边界 → 智能体作用 → 技术架构 → 完整流程 → 长文效果 → 评测方法 → 四档模型对比 → 性能与部署 → 创新优势 → 外部验证 → 交付与下一阶段 → 收束。
