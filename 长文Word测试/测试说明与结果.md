# 长文 Word 测试说明与结果

## 测试文件

- `长文测试_原始报告.docx`：待导入的长文 Word，24 章、约 1.7 万字、337 个段落（含表格单元格）、8 张普通表格。
- `配套数据_初始.xlsx`：与原始 Word 对应的初始数据。
- `配套数据_轻微变化.xlsx`：仅把销售额 125 改为 123 的更新数据。
- `配套数据_更新后.xlsx`：销售额 90、A 产品销量 60、支出 110 的较大变化数据。
- `长文测试_轻微变化结果.docx`、`长文测试_修复结果.docx`：对应更新后的修复下载结果。

## 怎么测试

1. 在知链中先上传 `长文测试_原始报告.docx` 和 `配套数据_初始.xlsx`，完成事实关联确认。
2. 后续只上传一个新的 Excel。本次测试中先使用 `配套数据_轻微变化.xlsx`，查看预览后执行修复并下载 Word。
3. 如果要测试更大范围的联动，再单独上传 `配套数据_更新后.xlsx`，不要把两个更新 Excel 同时上传。

## 自动化结果

- 初始导入识别 280 项论断，280 项一致。
- 轻微变化：80 项需要修复，修复后 280 项一致；全文与独立预期文本一致。
- 较大变化：232 项需要修复，修复后 280 项一致；全文与独立预期文本一致。
- 两种场景均验证了撤销修复和撤销数据更新。
- 修复前后段落样式、段落属性、行属性保持不变；Word 文档 XML 中除正文外的 18 个部件保持不变。
- WPS 原生渲染核验：三个 Word 版本均为 24 页；逐页检查了分页、表格、页眉、页脚和更新后的数字显示。

## 边界

这是长文和重复引用压力测试，6 个事实在多个章节中重复出现，用来验证定位和批量修复。中文数字句“约为一百二十五万元”以及背景编号、批次号、附件页码故意保留为人工复核内容。当前测试覆盖普通正文段落和一级表格，不代表截图、文本框、复杂嵌套对象或 20 页以上 PPT 的结果；PPT 将另行测试。

自动化耗时是本机进程内 API 测量，不包含浏览器上传和网络延迟。
