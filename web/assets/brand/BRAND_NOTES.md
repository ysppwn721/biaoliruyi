# 知链 Logo 方向

本目录提供 3 套可直接用于网页和软件产品的矢量 Logo 方向。当前只新增品牌素材，没有替换现有网页界面，便于团队先评审方向。

## 方向

- `concept-a`：链证。两个相扣的链环与校验勾，表达“来源关联、重新核验、局部修复”的完整闭环。最适合网页导航、应用图标和托盘图标。
- `concept-b`：证页。打开的文档页叠加证据路径，表达“Word/PPT/Excel 与结论之间的依据关系”。最适合交付物、报告页和演示材料。
- `concept-c`：证据流。节点网络落到已核验状态，表达依赖图、智能体轨迹和可追溯性。最适合技术版官网、架构图和开发者文档。

## 文件说明

- `*-lockup.svg`：横版组合标，适合网页头部、启动页、演示材料。
- `*-icon.svg`：带底色纯图形，适合快捷图标、托盘、favicon。
- `*-mono.svg`：单色纯图形，适合黑白打印、浅色/深色系统托盘和水印。
- `brand-board.svg`：三套方向的对比稿。

## 使用建议

优先建议从 A 版开始做小尺寸实测：16 px、24 px、32 px 托盘/菜单图标下仍有明确的链路与校验语义。网页主标可以使用 A 版或 B 版横版组合标，C 版更适合技术叙事场景。

主色：

- A：`#176852` / `#75AD91` / `#C9823D`
- B：`#2C6255` / `#94C3A4` / `#C9823D`
- C：`#203B53` / `#5F9F86` / `#E4A261`

所有图形源文件均为 SVG，后续选定方向后可再统一导出 16/20/24/32/48/64/128/256/512 px PNG 及 Windows ICO，并把选定版本接入网页 favicon、桌面快捷方式和托盘资源。
